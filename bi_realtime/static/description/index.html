AKREM BI Realtime for Odoo 17

Live KPI dashboards synced with your business documents

By AKREM.KHELIFI. When you create or post invoices, sales orders, or CRM activities, KPIs and charts refresh instantly via Odoo Bus.

Interactive dashboards

Drag-and-drop layout, Chart.js charts, 6 visual themes, Excel and JSON export, department tabs (Sales, CRM, Stock, Accounting, HR, Purchase, POS).

Key features

  • KPIs from native Odoo models (sales, invoices, CRM, stock, purchases, POS)
  • Automatic sync on document create or post (Odoo Bus)
  • Email alerts, period comparisons, PDF reports
  • Optional AI assistant (system parameter bi_realtime.ai_api_url)
  • Custom KPIs, DAX-style measures, scheduled refresh

Configuration

  1. Install the module and open AKREM BI Realtime then Dashboard.
  2. Create KPIs with source Odoo and the matching model (e.g. account.move for invoices).
  3. Optional: set bi_realtime.ai_api_url for the AI assistant API.
