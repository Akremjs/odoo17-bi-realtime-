BI Realtime pour Odoo 17

Dashboards KPI synchronisés avec vos actions métier

Fonctionnalités

  • Dashboards interactifs (Chart.js, thèmes, export JSON/Excel)
  • KPIs calculés depuis Odoo (ventes, factures, CRM, stock, achats, POS)
  • Synchronisation automatique : création/validation d'une facture ou commande → rafraîchissement des KPIs et du dashboard (Bus Odoo)
  • Alertes email, comparaisons N vs N-1, rapports PDF
  • IA optionnelle via URL d'API configurable (Groq / service externe)

Configuration

Paramètres système : bi_realtime.ai_api_url (API IA, optionnel). Les KPIs doivent utiliser la source Odoo et le modèle métier correspondant (ex. account.move pour les factures).

Extension architecture Kafka/Spark (projet PFE) : disponible dans le dépôt Git complet, non requise pour l'utilisation standard du module.
