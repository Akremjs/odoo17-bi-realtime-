❓ Questions Fréquentes (FAQ)

📦 Kafka ou Docker requis ?

Non ! Pour un usage standard Odoo, aucune infrastructure externe n'est nécessaire. Le module fonctionne nativement avec Odoo 17.

Ce module est conçu pour Odoo 17.0. Vérifiez la compatibilité avec votre instance.

🤖 Comment activer l'IA ?

L'IA est optionnelle. Configurez le paramètre système bi_realtime.ai_api_url pour connecter votre propre API d'intelligence artificielle.

⚙️ Installation difficile ?

Pas du tout ! Installation en 3 étapes : installez le module, ouvrez le menu Dashboard, configurez vos KPIs. C'est tout !
