BI en temps réel for Odoo 17

Live KPI dashboards synced with your business documents

By AKREM.KHELIFI — create or validate an invoice, sales order, or CRM activity → KPIs and charts refresh instantly via Odoo Bus.

Interactive dashboards

Drag-and-drop layout, 18+ Chart.js chart types, 6 visual themes, Excel / JSON export, and department tabs (Sales, CRM, Stock, Accounting, HR, Purchase, POS).

Key features

  • KPIs from native Odoo models (sales, invoices, CRM, stock, purchases, POS)
  • Automatic sync on document create / post (Odoo Bus WebSocket)
  • Email alerts, N vs N-1 comparisons, PDF reports
  • Optional AI assistant (configurable API URL: Groq or external service)
  • DAX-style measures, custom KPIs, scheduled refresh

Configuration

  1. Install the module and open BI en temps réel → Dashboard.
  2. Create KPIs with source Odoo and the matching model (e.g. account.move for invoices).
  3. Optional: set system parameter bi_realtime.ai_api_url for the AI assistant.
